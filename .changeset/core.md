Initial release: framework-neutral emoji data, search, frequently used emoji, skin tones, custom emoji, and typeahead state, with no runtime dependencies. `createEmojiStore` returns an `EmojiStore` with `setOptions`, `load`, `prepare`, search, and frequently used emoji (`pick`, `remove`, `clear`); `data` defaults to `@emoji-components/data`'s English dataset on jsDelivr, `search` takes any `EmojiSearch` (default `lexical()`), `customEmojis` takes a list or a loader, and uncontrolled frequents and skin tone persist to `localStorage` (controlled `frequents` and `skinTone` keep them elsewhere). Change callbacks get Base UI-style `ChangeDetails` (`reason`, `event`, `trigger`, `cancel()`), typed per option and exported from the main entry. `createEmojiPicker` is the picker's headless state, `createEmojiSuggestions` drives editor typeaheads with `syncCombobox(el)`, and `createSearch` gives search-as-you-type state. `/grid` and `/native` hold layout math and native-support detection; `/build` and the `emoji-components build-data` CLI build datasets from `emojibase-data`.
