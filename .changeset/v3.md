v3: headless, unstyled React parts for emoji pickers, tapbacks and shortcode autocomplete, built on React Aria, with copy-in components from the shadcn registry. Framework-neutral state, data, search and the ProseMirror plugin move to the new `@brianhung/emoji-picker-core` package, which this one depends on; it also owns the `emoji-picker build-data` CLI and `data/en.json`. Popover adapters for Floating UI (`/floating-ui`) and React Aria (`/react-aria`), and editor typeahead for Tiptap and Lexical. Breaking: the package is ESM-only, needs React 18.2 or 19, and the picker's ARIA semantics and markup change; `EmojiPopover` and `EmojiSuggestions.Popover` are exported only from `/floating-ui` and `/react-aria`, `@floating-ui/react` is an optional peer dependency, the `/core`, `/search`, `/prosemirror` and `/data/en.json` subpaths are now `@brianhung/emoji-picker-core`, `@brianhung/emoji-picker-core/search`, `@brianhung/emoji-picker-core/prosemirror` and `@brianhung/emoji-picker-core/data/en.json`, and the root re-exports only the core types React code commonly needs. See the CHANGELOG for the full list.
