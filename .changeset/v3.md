v3: headless, unstyled React parts for emoji pickers, tapbacks and shortcode autocomplete, built on React Aria, with copy-in components from the shadcn registry. Adds framework-neutral state in `/core`, popover adapters for Floating UI (`/floating-ui`) and React Aria (`/react-aria`), editor typeahead for Tiptap, Lexical and ProseMirror, and the `emoji-picker build-data` CLI for localized datasets. Breaking: the package is ESM-only, needs React 18.2 or 19, and the picker's ARIA semantics and markup change. See the CHANGELOG for the full list.
