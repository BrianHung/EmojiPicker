Initial release: unstyled React parts for emoji pickers, reaction rows and shortcode autocomplete, built on React Aria, with copy-in components in the shadcn registry. Popover adapters for Floating UI (`/floating-ui`) and React Aria (`/react-aria`), and typeahead hooks for text fields and any editor. ESM-only client modules; React 18.2 or 19.
