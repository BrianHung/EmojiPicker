Initial release: unstyled React parts for emoji pickers, reaction rows, and shortcode typeahead, with Base UI's API shape (parts with `render`, `className`, and `style` as functions of state, `x`/`defaultX`/`onXChange(value, eventDetails)`, `actionsRef`, empty-string state attributes, and `preventEmojiPickerHandler()` on every composed handler) and React Aria's behavior, with copy-in components in the shadcn registry. Types are namespaced (`EmojiPicker.Root.Props`, `.State`, `.Actions`, `.ChangeEventDetails`, `.ChangeEventReason`, `EmojiProvider.Props`, `EmojiPopover.Root.Props`), with flat `EmojiPicker…`/`EmojiPopover…` names behind them, next to a few domain types such as `EmojiSelection` and `CustomEmoji`. Parts and hooks are client modules behind server-safe entry points, and the parts are one-level namespaces as in Base UI (`EmojiPicker.SearchInput`, `EmojiPicker.ListCell`), so a Server Component renders any part through them. `EmojiProvider` takes `data`, `customEmojis`, `filter`, `search`, `locale`, `labels`, and controlled or uncontrolled `frequents` and `skinTone`. Popovers come from `/floating-ui` or `/react-aria` with the same parts as Base UI's Popover (`EmojiPopover.Root`, `.Trigger`, `.Portal`, `.Positioner`, `.Popup`) and the same props, including `container`, `side`, `align`, `sideOffset`, `alignOffset`, `initialFocus`, and `finalFocus`, and its `--anchor-*`, `--available-*`, and `--transform-origin` variables; `EmojiSuggestions` places a typeahead menu at the caret with the parts of Base UI's Combobox popup. `Positioner`'s `anchor` takes Base UI's forms: an element, a ref, a virtual element, or a function. `EmojiPicker.SearchStatus` places and styles the result count's live region, as Base UI's `Combobox.Status`; without it, Root renders a visually hidden one. `Emoji` forwards its ref and takes `aria-hidden` to hide itself from assistive technology. A pick closes an `EmojiPopover` with reason `item-press`, which `details.cancel()` keeps open. `useTextFieldEmojiTypeahead(ref)` and `useEmojiTypeahead(trigger | suggestions)` cover text fields and editors. The entry points are ESM-only and support React 18.2 and 19.
