Initial release: unstyled React parts for emoji pickers, reaction rows, and shortcode typeahead, with Base UI's API shape (parts with `render`, `className`, and `style` as functions of state, `x`/`defaultX`/`onXChange(value, eventDetails)`, `actionsRef`, empty-string state attributes, and `preventEmojiPickerHandler()` on every composed handler) and React Aria's behavior, with copy-in components in the shadcn registry. Types are namespaced (`EmojiPicker.Root.Props`, `.State`, `.Actions`, `.ValueChangeEventDetails`, `EmojiProvider.Props`, `EmojiPopover.Root.Props`), next to a few domain types such as `EmojiSelection` and `CustomEmoji`. `EmojiProvider` takes `data`, `customEmojis`, `filter`, `search`, `locale`, `labels`, and controlled or uncontrolled `frequents` and `skinTone`. Popovers come from `/floating-ui` or `/react-aria` with the same props. `useTextFieldEmojiTypeahead(ref)` and `useEmojiTypeahead(trigger | suggestions)` cover text fields and editors. The entry points are ESM-only client modules and support React 18.2 and 19.
