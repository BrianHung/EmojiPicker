Initial release: unstyled React parts for emoji pickers, reaction rows, and shortcode typeahead, built on React Aria, with copy-in components in the shadcn registry. Includes popover adapters for Floating UI (`/floating-ui`) and React Aria (`/react-aria`), and typeahead hooks for text fields and any editor. The entry points are ESM-only client modules and support React 18.2 and 19.
