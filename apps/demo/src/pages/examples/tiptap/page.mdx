## Usage

`EmojiNode` draws custom emoji, which are images, in the document. Without custom emoji, leave it out. The picker button needs the `emoji-picker-popover.json` item from [Installation](/#installation).

```tsx title="editor.tsx"
"use client";

import { EditorContent, useEditor } from "@tiptap/react";
import StarterKit from "@tiptap/starter-kit";
import { EmojiProvider, useEmojiStore } from "emoji-components";
import { EmojiPickerPopover } from "@/components/ui/emoji-picker-popover";
import { EmojiNode, emojiAttrs } from "@/components/tiptap/emoji-node";
import { EmojiSuggestionMenu } from "@/components/tiptap/emoji-suggestion";

function TiptapEditor() {
  const store = useEmojiStore();
  const editor = useEditor({ extensions: [StarterKit, EmojiNode.configure({ store })], immediatelyRender: false });
  if (!editor) return null;
  return (
    <>
      <EmojiPickerPopover
        aria-label="Insert emoji"
        onSelect={(selection) => {
          const attrs = selection.isCustom ? emojiAttrs(store, selection.unified) : null;
          if (attrs) editor.chain().focus().insertEmoji(attrs).run();
          else editor.chain().focus().insertContent(selection.emoji).run();
        }}
      >
        🙂
      </EmojiPickerPopover>
      <EditorContent editor={editor} />
      <EmojiSuggestionMenu editor={editor} />
    </>
  );
}

export function Editor() {
  return (
    <EmojiProvider>
      <TiptapEditor />
    </EmojiProvider>
  );
}
```

`immediatelyRender: false` renders the editor after hydration, as Tiptap requires with server rendering. With Next.js Cache Components, render `<Editor />` inside `<Suspense>`, since Tiptap calls `Math.random()` while it renders.

## How it works

`useTiptapEmojiTypeahead` registers the ProseMirror plugin on the editor. The plugin finds the `:query`, ranks the matches, and handles the keys. `EmojiSuggestions.Positioner` positions the menu at the typed `:query`.

```tsx title="emoji-suggestion.tsx (excerpt)"
import { useTiptapEmojiTypeahead } from "@/hooks/use-emoji-tiptap";

const emoji = useTiptapEmojiTypeahead(editor, {
  content: (text, { record, shortcode }) => (record.imageUrl ? emojiContent({ unified: record.unified, shortcode, text: null }) : `${text} `),
});

<EmojiSuggestions.Root open={emoji.open} onOpenChange={(open) => !open && emoji.dismiss()}>
  <EmojiSuggestions.Portal>
    <EmojiSuggestions.Positioner anchor={emoji.anchor}>
      <EmojiSuggestions.Popup>
        <ul {...emoji.suggestions.getListProps()}>
          {emoji.suggestions.suggestions.map((s, i) => <li key={s.shortcode} {...emoji.suggestions.getOptionProps(i)}>:{s.shortcode}:</li>)}
        </ul>
      </EmojiSuggestions.Popup>
    </EmojiSuggestions.Positioner>
  </EmojiSuggestions.Portal>
</EmojiSuggestions.Root>
```
