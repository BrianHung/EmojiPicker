## Usage

Each `group` becomes its own section.

```tsx title="picker.tsx"
"use client";

import { EmojiPicker, EmojiProvider, type CustomEmoji } from "emoji-components";

const bufo = async ({ signal }: { signal: AbortSignal }): Promise<CustomEmoji[]> => (await fetch("/packs/bufo/pack.json", { signal })).json();

export function Picker() {
  return (
    <EmojiProvider customEmojis={bufo}>
      <EmojiPicker.Root categories={[{ id: "custom:Bufo" }, { id: "smileys-people" }]}>
        <EmojiPicker.Viewport style={{ height: 320 }}>
          <EmojiPicker.List />
        </EmojiPicker.Viewport>
      </EmojiPicker.Root>
    </EmojiProvider>
  );
}
```

## Host a pack

A pack is a static `pack.json`, fetched at runtime, as in this site's [example pack](/packs/bufo/pack.json). Images load as `<img>` elements and need no CORS headers. Under a strict Content Security Policy, host the images yourself.

```json title="pack.json"
[
  {
    "id": "bufo-party",
    "name": "bufo party",
    "imageUrl": "https://all-the.bufo.zone/bufo-party.gif",
    "shortcodes": ["bufo-party"],
    "group": "Bufo",
    "width": 128,
    "height": 128,
    "animated": true,
    "stillUrl": "/api/bufo-still/bufo-party.gif"
  }
]
```

## Load a pack by URL

Enter a `pack.json` URL to load it. A pack on another origin must be served with CORS. This loader resolves relative `imageUrl`s against the pack's URL.

## Large packs

- Fetch the pack by URL after the page loads, and keep it out of the bundle.
- Ship small thumbnails (64px WebP is about 2 KB each).
- Only visible cells request images.
- Animated GIFs play in the grid. Mark them `animated: true`, and add a `stillUrl` to show under reduced motion.
- Give each emoji a readable `name` (“party parrot”, not `partyParrot`); search matches each word.
