## Installation

The packages are in prerelease (`1.0.0-alpha`), and the API can change between alphas.

<TabPanels label="Installation">

<TabPanel label="Command">

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-picker.json" />

The command adds `components/ui/emoji-picker.tsx`, installs `emoji-components`, and adds the emoji font stack and the picker's background, radius, and shadow tokens to your CSS.

```tsx title="App.tsx"
import { EmojiPickerCard } from "@/components/ui/emoji-picker";

export default function App() {
  return <EmojiPickerCard onSelect={(selection) => console.log(selection.emoji)} />;
}
```

`EmojiPickerCard` takes the props of `EmojiPicker.Root`, plus `cell`, `footer`, and `empty`. The file also exports `EmojiTapback`, a reaction row that expands into the picker.

To open the picker from your shadcn/ui popover, add the popover item too:

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-picker-popover.json" />

With the React Aria base (`--base aria`), add this item instead:

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-picker-popover-react-aria.json" />

```tsx title="add-reaction.tsx"
"use client";

import { EmojiPickerPopover } from "@/components/ui/emoji-picker-popover";

export function AddReaction({ onAdd }: { onAdd: (unified: string) => void }) {
  return (
    <EmojiPickerPopover aria-label="Add reaction" onSelect={(selection) => onAdd(selection.unified)}>
      🙂
    </EmojiPickerPopover>
  );
}
```

For the reactions under a message, `emoji-reaction-bar.json` adds a React Aria toolbar around your own buttons: the arrow keys, Home, and End move focus between them.

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-reaction-bar.json" />

```tsx title="reactions.tsx"
"use client";

import { Emoji } from "emoji-components";
import { EmojiReactionBar } from "@/components/ui/emoji-reaction-bar";

type Reaction = { unified: string; count: number; mine: boolean };

export function Reactions({ reactions, onToggle }: { reactions: Reaction[]; onToggle: (unified: string) => void }) {
  return (
    <EmojiReactionBar aria-label="Reactions">
      {reactions.map((r) => (
        <button key={r.unified} type="button" aria-pressed={r.mine} onClick={() => onToggle(r.unified)}>
          <Emoji emoji={r.unified} /> {r.count}
        </button>
      ))}
    </EmojiReactionBar>
  );
}
```

## Usage

The parts work without an `EmojiProvider` or CSS. `Root` loads the English dataset from jsDelivr, and `Viewport` needs a fixed height to virtualize the list. Add `EmojiProvider` to change the data, locale, search, renderer, labels, or custom emoji; without one, the parts share a default store.

```tsx title="app/page.tsx"
"use client";

import { EmojiPicker } from "emoji-components";

export default function Page() {
  return (
    <EmojiPicker.Root onSelect={(selection) => console.log(selection.emoji)}>
      <EmojiPicker.Search>
        <EmojiPicker.SearchInput />
      </EmojiPicker.Search>
      <EmojiPicker.Viewport style={{ height: 320 }}>
        <EmojiPicker.List />
      </EmojiPicker.Viewport>
    </EmojiPicker.Root>
  );
}
```

### Suggesting shortcodes {#headless}

## API reference

Every part forwards its ref, spreads other props onto its element, and takes these props.

<PropsTable rows={api.part} />

A handler you pass to a part runs before the part's own. Call `event.preventEmojiComponentsHandler()` to skip the part's handler.

Each controllable state has three props, such as `query`, `defaultQuery`, and `onQueryChange(value, details)`. `details.cancel()` keeps the current state. Callbacks that Escape can trigger also have `details.allowPropagation()`, which lets the key event reach the page.

`EmojiPicker`, `EmojiPopover`, and `EmojiSuggestions` are namespaces, as in Base UI, so a Server Component can render their parts. A function child can't come from a Server Component, so render parts that need one, such as `ListCell` inside `List`, in a Client Component.

Shared types: `EmojiSelection`, `EmojiItem`, `EmojiRecord`, `CustomEmoji`, `CategoryOption`, `Dataset`, `EmojiDataInput`, `EmojiSearch`, `EmojiLabels`, `Frequents`, `SkinToneValue`, `EmojiImageUrl`, `EmojiStore`.

`onSelect` receives an `EmojiSelection`. Insert `emoji` as text, or, for a custom emoji, draw `imageUrl` or keep `shortcode`.

<DefList rows={api.selection} />
