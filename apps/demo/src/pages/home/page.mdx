## Installation

The packages are in prerelease (`1.0.0-alpha`), and the API can change between alphas.

<TabPanels label="Installation">

<TabPanel label="Command">

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-picker.json" />

The command adds `components/ui/emoji-picker.tsx`, installs `emoji-components`, and adds the emoji font stack and the picker's background, radius, and shadow tokens to your CSS.

```tsx title="App.tsx"
import { EmojiPicker, EmojiPickerContent, EmojiPickerFooter, EmojiPickerSearch } from "@/components/ui/emoji-picker";

export default function App() {
  return (
    <EmojiPicker onSelect={(selection) => console.log(selection.emoji)}>
      <EmojiPickerSearch />
      <EmojiPickerContent />
      <EmojiPickerFooter />
    </EmojiPicker>
  );
}
```

Each component in the file wraps one part and takes its props: `EmojiPicker` takes `EmojiPicker.Root`'s, `EmojiPickerSearch` the `SearchInput`'s, and `EmojiPickerContent` the `Viewport`'s, with a function child for each cell, such as `{() => <EmojiPickerCell />}`. `EmojiPickerSkinTone`, `EmojiPickerEmpty`, `EmojiPickerReactions`, and `EmojiPickerPanel` style the rest. For a reaction row that expands into the picker:

```tsx title="reactions.tsx"
<EmojiPicker reactions={5} onSelect={(selection) => console.log(selection.emoji)}>
  <EmojiPickerReactions />
  <EmojiPickerPanel>
    <EmojiPickerSearch />
    <EmojiPickerContent />
  </EmojiPickerPanel>
</EmojiPicker>
```

The package renders no popovers. To open the picker from your shadcn/ui popover (Base UI or Radix base), add the popover item too:

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-picker-popover.json" />

With the React Aria base (`--base aria`), add `emoji-picker-popover-react-aria.json` instead; on Floating UI, without a shadcn/ui popover, add `emoji-picker-popover-floating-ui.json`. Each writes `components/ui/emoji-picker-popover.tsx`, which you own.

```tsx title="add-reaction.tsx"
"use client";

import { EmojiPickerPopover } from "@/components/ui/emoji-picker-popover";

export function AddReaction({ onAdd }: { onAdd: (unified: string) => void }) {
  return (
    <EmojiPickerPopover aria-label="Add reaction" onSelect={(selection) => onAdd(selection.unified)}>
      🙂
    </EmojiPickerPopover>
  );
}
```

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-suggestions.json" />

For the reactions under a message, `emoji-reaction-bar.json` adds `EmojiReactionBar`, React Aria's `useToolbar` around your own buttons: the arrow keys, Home, and End move focus between them, and once focus is inside, the pointer carries it.

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-reaction-bar.json" />

```tsx title="reactions.tsx"
"use client";

import { Emoji } from "emoji-components";
import { EmojiReactionBar } from "@/components/ui/emoji-reaction-bar";

type Reaction = { unified: string; count: number; mine: boolean };

export function Reactions({ reactions, onToggle }: { reactions: Reaction[]; onToggle: (unified: string) => void }) {
  return (
    <EmojiReactionBar aria-label="Reactions">
      {reactions.map((r) => (
        <button key={r.unified} type="button" aria-pressed={r.mine} onClick={() => onToggle(r.unified)}>
          <Emoji emoji={r.unified} /> {r.count}
        </button>
      ))}
    </EmojiReactionBar>
  );
}
```

For an editor, the [Tiptap](/examples/tiptap/) and [Lexical](/examples/lexical/) items render the same Floating UI menu.

## Usage

Each part renders a sensible default with no children. The parts work without an `EmojiProvider` or CSS. `Root` loads the English dataset from jsDelivr, and `Viewport` needs a fixed height to virtualize the list. Add `EmojiProvider` to change the data, locale, search, renderer, labels, or custom emoji; without one, the parts share a default store.

```tsx title="app/page.tsx"
"use client";

import { EmojiPicker } from "emoji-components";

export default function Page() {
  return (
    <EmojiPicker.Root onSelect={(selection) => console.log(selection.emoji)}>
      <EmojiPicker.Search />
      <EmojiPicker.Viewport style={{ height: 320 }} />
    </EmojiPicker.Root>
  );
}
```

## Examples

Imports from `@/components/ui/*` are the registry items from [Installation](#installation).

### Styling the parts {#inline}

Each part takes `className` and `style` as a value or a function of its state. `emoji-components/theme.css` adds Tailwind utilities for the tokens, such as `bg-emoji-picker-background`.

```css title="app/globals.css"
@import "tailwindcss";
@import "emoji-components/tokens.css";
@import "emoji-components/theme.css";
```

<Demo name="inline-picker" />

### Opening in a popover {#popover}

Use your own popover; the registry items above are one each for shadcn/ui, React Aria, and Floating UI. The glue is three things:

- Close the popover in `onSelect`, unless `details.isCanceled`.
- Pass `emojiPickerInitialFocus(popup)` as the popover's initial focus: the field with `autoFocus`, else the list.
- Leave Escape to the picker: the first Escape clears the query, and an Escape with nothing to clear goes on to the popover. Radix listens for Escape before the picker does, so it closes on the first one.

The popover returns focus to its trigger.

<Demo name="popover" className="min-h-[180px] flex-col gap-3" />

### Suggesting shortcodes {#headless}

`useTextFieldEmojiSuggestions(options, ref)` finds the `:query` before the caret in an `<input>` or `<textarea>` and handles the field's keys. It returns the matches and prop getters for your menu, and `anchor`, the query's box as a Floating UI virtual element, so positioning the menu is `refs.setPositionReference(anchor)`. For an editor, see the [Tiptap](/examples/tiptap/) and [Lexical](/examples/lexical/) examples.

<Demo name="autocomplete" className="min-h-[360px] items-end pb-14 sm:pb-14" />

### Showing a reaction row {#tapback}

`reactions` on `Root` shows a row of emoji in `Reactions` that expands into the picker in `Panel`. A selection in `Panel` shows the row again.

```tsx title="reactions.tsx"
<EmojiPicker.Root reactions={5}>
  <EmojiPicker.Reactions />
  <EmojiPicker.Panel>…</EmojiPicker.Panel>
</EmojiPicker.Root>
```

## API reference

Every part forwards its ref, spreads other props onto its element, and takes these props.

<PropsTable rows={api.part} />

A handler you pass to a part runs before the part's own. Call `event.preventEmojiComponentsHandler()` to skip the part's handler.

Each controllable state has three props, such as `query`, `defaultQuery`, and `onQueryChange(value, details)`. `details.cancel()` keeps the current state. Callbacks that Escape can trigger also have `details.allowPropagation()`, which lets the key event reach the page.

`EmojiPicker` is a namespace, as in Base UI, so a Server Component can render its parts. A function child can't come from a Server Component, so render parts that need one, such as `ListCell` inside `List`, in a Client Component.

Shared types: `EmojiSelection`, `EmojiItem`, `EmojiRecord`, `CustomEmoji`, `CategoryOption`, `Dataset`, `EmojiDataInput`, `EmojiSearch`, `EmojiLabels`, `Frequents`, `SkinToneValue`, `EmojiImageUrl`, `EmojiStore`.

`onSelect` receives an `EmojiSelection`. Insert `emoji` as text, or, for a custom emoji, draw `imageUrl` or keep `shortcode`.
