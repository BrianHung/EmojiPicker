## Usage

### Parts

Parts render with no provider and no CSS. `Root` loads the English dataset from jsDelivr.

```tsx title="picker.tsx"
<EmojiPicker.Root onSelect={(selection) => insert(selection.emoji)}>
  <EmojiPicker.Search>
    <EmojiPicker.Search.Input />
  </EmojiPicker.Search>
  <EmojiPicker.Viewport className="h-80">
    <EmojiPicker.List />
  </EmojiPicker.Viewport>
</EmojiPicker.Root>
```

### Styled

Import `@brianhung/emoji-picker-react/theme.css` for Tailwind utilities on the tokens, such as `bg-picker-background`. Every part takes `className` and `style` as a value or a function of its state, and writes its state as data attributes.

```tsx title="picker.tsx"
<EmojiPicker.Root className="w-80 rounded-picker bg-picker-background shadow-picker [--emoji-size:24px]">
  <EmojiPicker.Viewport className="h-80">
    <EmojiPicker.List>
      {() => <EmojiPicker.List.Items>{() => <EmojiPicker.List.Cell className="rounded-md data-highlighted:bg-picker-selected" />}</EmojiPicker.List.Items>}
    </EmojiPicker.List>
  </EmojiPicker.Viewport>
</EmojiPicker.Root>
```

### In a popover

The registry component takes your shadcn/ui theme, and its popover item uses your `components/ui/popover`.

```tsx title="message.tsx"
import { EmojiPickerPopover } from "@/components/ui/emoji-picker-popover";

<EmojiPickerPopover onSelect={(selection) => react(message.id, selection.unified)}>🙂 Add reaction</EmojiPickerPopover>
```

## API reference

Each part forwards its ref, spreads other props onto its element, and takes `render`, `className`, and `style`. Your handlers run before the part's; `event.preventEmojiPickerHandler()` skips the part's.

<PropsTable rows={api.part} />

### EmojiProvider {#api-provider}

The dataset, search, frequently used emoji, and skin tone for the parts and hooks inside it.

<PropsTable rows={api.provider} />

Types: `EmojiProvider.Props`, `EmojiProvider.SkinToneChangeEventDetails`, `EmojiProvider.FrequentsChangeEventDetails`.

### Root {#api-root}

Contains a picker. Each controllable state takes `x`, `defaultX`, and `onXChange(value, details)`; `details.cancel()` keeps the current state, and `details.allowPropagation()` lets an Escape reach the page. To drive the picker from an editor that keeps focus, pass it as `keyboardTarget`, or call `actionsRef`.
