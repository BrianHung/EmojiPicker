## Installation

The packages are in prerelease (`1.0.0-alpha`), and the API can change between alphas.

<TabPanels label="Installation">

<TabPanel label="Command">

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-picker.json" />

The command adds `components/ui/emoji-picker.tsx` to your project, and the emoji font stack and the picker tokens to your CSS.

```tsx title="App.tsx"
import { EmojiPickerCard } from "@/components/ui/emoji-picker";

export default function App() {
  return <EmojiPickerCard onSelect={(selection) => console.log(selection.emoji)} />;
}
```

To open the picker from your shadcn/ui popover, add the popover item too:

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-picker-popover.json" />

<PackageManagers dlx="shadcn@latest add https://cdn.jsdelivr.net/npm/emoji-components@latest/r/emoji-picker-popover-react-aria.json" />

```tsx title="message.tsx"
import { EmojiPickerPopover } from "@/components/ui/emoji-picker-popover";

<EmojiPickerPopover onSelect={(selection) => react(message.id, selection.unified)}>
  🙂 Add reaction

```

## Examples

### Composing a picker {#parts}

The parts render without a provider or CSS, `Root` loads the English dataset from jsDelivr, and `Viewport` needs a height to virtualize the list.

```tsx title="app/page.tsx"
"use client";

import { EmojiPicker } from "emoji-components";

export default function Page() {
  return (
    <EmojiPicker.Root onSelect={(selection) => console.log(selection.emoji)}>
      <EmojiPicker.Search>
        <EmojiPicker.SearchInput />
      </EmojiPicker.Search>
      <EmojiPicker.Viewport style={{ height: 320 }}>
        <EmojiPicker.List />
      </EmojiPicker.Viewport>
    </EmojiPicker.Root>
  );
}
```

### Styling the parts {#inline}

Each part takes `className` and `style` as a value or a function of its state, and `emoji-components/theme.css` adds Tailwind utilities for the tokens, such as `bg-emoji-picker-background`.

### Opening in a popover {#popover}

`EmojiPopover` comes from `emoji-components/floating-ui`, or from `emoji-components/react-aria`, where it is modal by default.

```tsx title="popover.tsx"
<EmojiPopover.Root>
  <EmojiPopover.Trigger />
  <EmojiPopover.Portal>
    <EmojiPopover.Positioner>
      <EmojiPopover.Popup>…</EmojiPopover.Popup>
    </EmojiPopover.Positioner>
  </EmojiPopover.Portal>
</EmojiPopover.Root>
```

<Demo name="popover" className="min-h-[180px] flex-col gap-3" adapters />

### Keeping the popover open {#keep-open}

A pick closes the popover with reason `"item-press"`, and canceling that change keeps it open.

```tsx title="picker-popover.tsx"
<EmojiPopover.Root onOpenChange={(open, details) => details.reason === "item-press" && details.cancel()}>
```

### Using another popover {#custom-popover}

In your own popover, close it from `onSelect` and give `SearchInput` `autoFocus`, or, without a search field, pass `emojiPickerInitialFocus` as the popover's initial focus.

```tsx title="emoji-button.tsx"
<Popover open={open} onOpenChange={setOpen}>
  <PopoverTrigger aria-label="Add emoji">😀</PopoverTrigger>
  <PopoverContent aria-label="Emoji picker" className="w-80 p-0">
    <EmojiPicker.Root onSelect={({ emoji }) => (onEmoji(emoji), setOpen(false))}>
      <EmojiPicker.Search>
        <EmojiPicker.SearchInput autoFocus />
      </EmojiPicker.Search>
      <EmojiPicker.Viewport className="h-72">
        <EmojiPicker.List />
      </EmojiPicker.Viewport>
    </EmojiPicker.Root>
  </PopoverContent>
</Popover>
```

### Showing a reaction row {#tapback}

`reactions` on `Root` shows a row of emoji in `Reactions` that expands into the picker in `Panel`.

### Suggesting shortcodes {#headless}

`useTextFieldEmojiTypeahead(ref)` finds a `:shortcode` as you type, and `EmojiSuggestions` shows the matches at the caret; for an editor, see the [Tiptap](/examples/tiptap/) and [Lexical](/examples/lexical/) examples.

```tsx title="suggestions.tsx"
<EmojiSuggestions.Root open={open} onOpenChange={(next) => !next && dismiss()}>
  <EmojiSuggestions.Portal>
    <EmojiSuggestions.Positioner anchor={anchor}>
      <EmojiSuggestions.Popup>…</EmojiSuggestions.Popup>
    </EmojiSuggestions.Positioner>
  </EmojiSuggestions.Portal>
</EmojiSuggestions.Root>
```

## API reference

Every part forwards its ref, spreads other props onto its element, and takes these props.

<PropsTable rows={api.part} />

A handler you pass to a part runs before the part's own, and `event.preventEmojiComponentsHandler()` skips the part's. Each controllable state takes `x`, `defaultX`, and `onXChange(value, details)`: `details.cancel()` keeps the current state, and `details.allowPropagation()` lets an Escape reach the page. `EmojiPicker`, `EmojiPopover`, and `EmojiSuggestions` are one-level namespaces, as in Base UI, so a Server Component can render any part through them; parts that a function child renders, such as `ListCell` inside `List`, belong in a Client Component.

Shared types: `EmojiSelection`, `EmojiItem`, `EmojiRecord`, `CustomEmoji`, `CategoryOption`, `Dataset`, `EmojiDataInput`, `EmojiSearch`, `EmojiLabels`, `Frequents`, `SkinToneValue`, `EmojiImageUrl`, `EmojiStore`.
