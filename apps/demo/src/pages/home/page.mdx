## Usage

### Shared provider {#provider}

Every part and hook uses the nearest `EmojiProvider`. Without one, they share a single store with the default options, so frequently used emoji and the skin tone agree across the page. Add a provider to set data, locale, custom emoji, or storage for everything below it.

<Code title="app/providers.tsx" code={providers} />

### Emoji data {#data}

`en.json` ships with core: 1,923 emoji from Emojibase, with iamcal shortcodes. By default, it loads from jsDelivr, pinned to the installed core version. To self-host, serve the file and pass its URL. `data` also takes a loader or the dataset object, and `filter` removes emoji from pickers and search.

<CodeTabs>

```tsx title="app/providers.tsx" label="Self-hosted"
// cp node_modules/@brianhung/emoji-picker-data/en/iamcal.json public/emoji/en.json
<EmojiProvider data="/emoji/en.json">
```

```tsx title="app/providers.tsx" label="Loader"
// A loader runs once per locale, however often the provider renders
<EmojiProvider locale={locale} data={({ signal }) => fetch(`/emoji/${locale}.json`, { signal }).then((r) => r.json())}>
```

```tsx title="app/providers.tsx" label="Filter"
<EmojiProvider filter={(e) => e.group !== "flags" && e.version <= 15}>
```

</CodeTabs>

### Localization {#localization}

`@brianhung/emoji-picker-data` has a dataset for every Emojibase locale and shortcode set. `localeData(locale, { shortcodes, baseUrl })`, from `@brianhung/emoji-picker-core`, returns a dataset's jsDelivr URL. The dataset localizes emoji names, tags, and section names. `shortcodes` defaults to `"iamcal"`, whose shortcodes are English in every locale; `"cldr"` gives shortcodes in the locale's language. `locale` sets search folding, A–Z order, and text direction.

The picker's strings and accessible names come from `labels`, a partial `EmojiLabels` that defaults to English. This example sets every key:

<Code title="app/providers.tsx" code={localization} />

To self-host, copy `node_modules/@brianhung/emoji-picker-data/data/` to `public/emoji/` and pass `baseUrl`: `localeData("ja", { baseUrl: "/emoji" })` resolves to `/emoji/ja/iamcal.json`. Under a strict package manager such as pnpm, add `@brianhung/emoji-picker-core` to your dependencies to import `localeData`.

### Emoji fonts {#fonts}

Native emoji draw in `--emoji-font-family`, so any color emoji font works. `@brianhung/emoji-picker-twemoji-font` is Twemoji as a color font, split into subsets that load as they are drawn.

<PackageManagers install="@brianhung/emoji-picker-twemoji-font" />

<CodeTabs>

```css title="app/globals.css" label="Twemoji"
@import "@brianhung/emoji-picker-twemoji-font/twemoji.css";

[data-slot="emoji-picker"] { --emoji-font-family: Twemoji; }
```

```css title="app/globals.css" label="Noto Color Emoji"
@import url("https://fonts.googleapis.com/css2?family=Noto+Color+Emoji&display=swap");

[data-slot="emoji-picker"] { --emoji-font-family: "Noto Color Emoji"; }
```

</CodeTabs>

Twemoji is licensed under CC-BY 4.0. Apps that show it should credit Twemoji, for example on an About page.

<PropsTable rows={api.part} />

### Root {#api-root}

Contains the parts of a picker.

<PropsTable rows={api.root} />

#### Controlled state

Each controllable state takes `x`, `defaultX`, and `onXChange(value, details)`. `details` has the `reason` and, when there is one, the `event`. `details.cancel()` keeps the current state. `details.allowPropagation()` lets an `"escape-key"` change of Root `query` or `SkinTone` `open` reach the page, such as a dialog around the picker. Changes made through `actionsRef` report `"imperative-action"`.

#### Keyboard

Each part handles its own keys with React Aria. A part's `onKeyDown` runs before the picker's handler. `event.preventEmojiPickerHandler()` skips the picker's handler for that key, and `event.preventDefault()` keeps its usual meaning. Keyboard and pointer move one highlight. With a search field, focus stays in the field (`aria-activedescendant`). Without one, focus moves through the cells.

To drive the picker from an editor that keeps focus, pass the editor as `keyboardTarget`, or call the actions from `actionsRef` (`useEmojiPickerActions()` inside `Root`).

```tsx title="editor-menu.tsx"
const actions = React.useRef<EmojiPickerActions>(null);

<EmojiPicker.Root query={query} keyboardTarget={editor.view.dom} actionsRef={actions} onKeyDown={(e) => e.key === "Escape" && e.preventEmojiPickerHandler()}>
  …
</EmojiPicker.Root>;

actions.current?.move("down");
actions.current?.pick();
```

## Advanced

### Floating UI or React Aria

`EmojiPopover`, `EmojiSuggestions.Popover` (a `:shortcode` menu at a text field's caret that never takes focus), and `pickerInitialFocus` come from either subpath. An app bundles only the one it imports. The React Aria `EmojiPopover` is modal: focus stays inside, and the page does not scroll until it closes. The React Aria `EmojiSuggestions.Popover` closes when the page scrolls and stays open on a press outside. For editor menus, use the Floating UI `EmojiSuggestions.Popover`.

```tsx title="imports.tsx"
import { EmojiPopover, EmojiSuggestions } from "@brianhung/emoji-picker-react/floating-ui"; // the default
import { EmojiPopover, EmojiSuggestions } from "@brianhung/emoji-picker-react/react-aria";
```

### Custom popover {#custom-popover}

A picker works in any popover. Close it from `onSelect`, and give the search field `autoFocus`. A picker without a search field takes `pickerInitialFocus` (from either popover subpath) as the popover's initial focus. A shadcn/ui project made with `--base aria` has React Aria's `PopoverTrigger` and `Popover` in place of `PopoverContent`.

<CodeTabs>

```tsx title="emoji-button.tsx" label="Base UI and Radix"
import * as React from "react";
import { EmojiPicker } from "@brianhung/emoji-picker-react";
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover";

export function EmojiButton({ onEmoji }: { onEmoji: (emoji: string) => void }) {
  const [open, setOpen] = React.useState(false);
  return (
    <Popover open={open} onOpenChange={setOpen}>
      <PopoverTrigger aria-label="Add emoji">😀</PopoverTrigger>
      <PopoverContent aria-label="Emoji picker" className="w-80 p-0">
        <EmojiPicker.Root
          onSelect={({ emoji }) => {
            onEmoji(emoji);
            setOpen(false);
          }}
        >
          <EmojiPicker.Search>
            <EmojiPicker.Search.Input autoFocus />
          </EmojiPicker.Search>
          <EmojiPicker.Viewport className="h-72">
            <EmojiPicker.List />
          </EmojiPicker.Viewport>
        </EmojiPicker.Root>
      </PopoverContent>
    </Popover>
  );
}
```

```tsx title="emoji-button.tsx" label="React Aria"
import * as React from "react";
import { EmojiPicker } from "@brianhung/emoji-picker-react";
import { Button } from "@/components/ui/button";
import { Popover, PopoverTrigger } from "@/components/ui/popover";

export function EmojiButton({ onEmoji }: { onEmoji: (emoji: string) => void }) {
  const [open, setOpen] = React.useState(false);
  return (
    <PopoverTrigger isOpen={open} onOpenChange={setOpen}>
      <Button variant="ghost" aria-label="Add emoji">
        😀
      </Button>
      <Popover aria-label="Emoji picker" className="w-80 p-0">
        <EmojiPicker.Root
          onSelect={({ emoji }) => {
            onEmoji(emoji);
            setOpen(false);
          }}
        >
          <EmojiPicker.Search>
            <EmojiPicker.Search.Input autoFocus />
          </EmojiPicker.Search>
          <EmojiPicker.Viewport className="h-72">
            <EmojiPicker.List />
          </EmojiPicker.Viewport>
        </EmojiPicker.Root>
      </Popover>
    </PopoverTrigger>
  );
}
```
