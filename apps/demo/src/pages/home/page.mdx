## Installation

The packages are in prerelease (`1.0.0-alpha`), and the API can change between alphas.

<TabPanels label="Installation">

<TabPanel label="Command">

Run `npx shadcn@latest init` first if your project doesn't use shadcn/ui yet.

<PackageManagers dlx="shadcn@latest add https://emoji.brianhung.me/r/emoji-picker.json" />

The command adds `components/ui/emoji-picker.tsx`, installs `emoji-components`, and imports `emoji-components/tokens.css` and `emoji-components/shadcn.css` into your CSS, so the picker follows your shadcn/ui theme.

```tsx title="App.tsx"
import { EmojiPicker, EmojiPickerContent, EmojiPickerFooter, EmojiPickerSearch } from "@/components/ui/emoji-picker";

export default function App() {
  return (
    <EmojiPicker onSelect={(selection) => console.log(selection.emoji)}>
      <EmojiPickerSearch />
      <EmojiPickerContent />
      <EmojiPickerFooter />
    </EmojiPicker>
  );
}
```

Each component wraps one part and takes its props. The file is yours to edit. A popover, a suggestions menu, and a reaction bar are separate items, under [Examples](#popover).

## Usage

Each part renders a default with no children, and works without CSS. `Viewport` needs a height to virtualize the list.

```tsx title="app/page.tsx"
"use client";

import { EmojiPicker } from "emoji-components";

export default function Page() {
  return (
    <EmojiPicker.Root onSelect={(selection) => console.log(selection.emoji)}>
      <EmojiPicker.Search />
      <EmojiPicker.Viewport style={{ height: 320 }} />
    </EmojiPicker.Root>
  );
}
```

`Root` loads the English dataset from jsDelivr. Wrap it in `EmojiProvider` to change the data, locale, search, labels, or custom emoji.

## Examples

### Styling the parts {#inline}

Each part takes `className` and `style` as a value or a function of its state. `emoji-components/theme.css` adds Tailwind utilities for the tokens, such as `bg-emoji-picker-background`.

```css title="app/globals.css"
@import "tailwindcss";
@import "emoji-components/tokens.css";
@import "emoji-components/theme.css";
```

<Demo name="inline-picker" />

To draw the search field with your own input component, pass it as `SearchInput`'s `render`:

```tsx title="search.tsx"
import { EmojiPicker } from "emoji-components";
import { Input } from "@/components/ui/input";

export function Search() {
  return (
    <EmojiPicker.Search className="relative">
      <EmojiPicker.SearchInput autoFocus render={<Input />} />
      <EmojiPicker.SearchClear />
    </EmojiPicker.Search>
  );
}
```

### Opening in a popover {#popover}

The package renders no popovers. For your shadcn/ui popover (Base UI or Radix base), add the popover item:

<PackageManagers dlx="shadcn@latest add https://emoji.brianhung.me/r/emoji-picker-popover.json" />

For the React Aria base, add `emoji-picker-popover-react-aria.json` instead. Without shadcn/ui, add `emoji-picker-popover-floating-ui.json`.

```tsx title="add-reaction.tsx"
"use client";

import { EmojiPickerPopover } from "@/components/ui/emoji-picker-popover";

export function AddReaction({ onAdd }: { onAdd: (unified: string) => void }) {
  return (
    <EmojiPickerPopover aria-label="Add reaction" onSelect={(selection) => onAdd(selection.unified)}>
      🙂
    </EmojiPickerPopover>
  );
}
```

In your own popover:

- Close it in `onSelect`, unless `details.isCanceled`.
- Pass `emojiPickerInitialFocus(popup)` as its initial focus.
- Leave Escape to the picker. The first Escape clears the search; the next closes the popover.

`finalFocus` returns focus somewhere other than the trigger, such as a message field.

### Suggesting shortcodes {#headless}

Typing a colon and two letters, such as `:sm`, suggests emoji at the caret. The suggestions item is the menu:

<PackageManagers dlx="shadcn@latest add https://emoji.brianhung.me/r/emoji-suggestions.json" />

<Code title="composer.tsx" code={composer} />

- `useTextFieldEmojiSuggestions(options, ref)` works with an `<input>` or `<textarea>`.
- An Enter that picks a suggestion doesn't reach your own Enter handler.
- For a rich text editor, pass the query yourself, as in the [Tiptap](/examples/tiptap/) and [Lexical](/examples/lexical/) examples:

```tsx
useEmojiSuggestions({
  trigger: { query: "sm", anchor: () => queryRect, replace: (text) => insertText(text) }, // or null
});
```

### Showing a reaction row {#tapback}

A row of quick reactions, as in a tapback, that expands into the full picker.

```tsx title="reactions.tsx"
<EmojiPicker.Root reactions={5}>
  <EmojiPicker.Reactions />
  <EmojiPicker.Panel>…</EmojiPicker.Panel>
</EmojiPicker.Root>
```

- `reactions={5}` shows the five most frequently used emoji. Pass an array for a fixed row, or to render the row on the server.
- `value` on `Reactions` makes the items toggle.

<Demo name="tapback" className="min-h-[180px] items-start pt-[62px] sm:pt-[62px]" />

With the registry component, drawn as a pill until it expands:

```tsx title="reactions.tsx"
<EmojiPicker
  reactions={5}
  onSelect={(selection) => console.log(selection.emoji)}
  className="data-reactions-open:rounded-full data-reactions-open:shadow-lg data-reactions-open:[corner-shape:round]"
>
  <EmojiPickerReactions />
  <EmojiPickerPanel>
    <EmojiPickerSearch />
    <EmojiPickerContent />
  </EmojiPickerPanel>
</EmojiPicker>
```

For the reactions under a message, with counts, the reaction bar item adds arrow-key navigation to your own buttons.

<PackageManagers dlx="shadcn@latest add https://emoji.brianhung.me/r/emoji-reaction-bar.json" />

```tsx title="reactions.tsx"
"use client";

import { Emoji } from "emoji-components";
import { EmojiReactionBar } from "@/components/ui/emoji-reaction-bar";

type Reaction = { unified: string; count: number; mine: boolean };

export function Reactions({ reactions, onToggle }: { reactions: Reaction[]; onToggle: (unified: string) => void }) {
  return (
    <EmojiReactionBar aria-label="Reactions">
      {reactions.map((r) => (
        <button key={r.unified} type="button" aria-pressed={r.mine} onClick={() => onToggle(r.unified)}>
          <Emoji emoji={r.unified} /> {r.count}
        </button>
      ))}
    </EmojiReactionBar>
  );
}
```

### Loading another locale {#data}

`locale` on `EmojiProvider` loads emoji names and keywords in that language, falling back to English.

The interface strings are yours to translate. `labels` takes strings and functions, so any i18n library works. With react-i18next:

<Code title="app/providers.tsx" code={localization} />

The data loads from jsDelivr. To serve it yourself, for offline use or a strict CSP, bundle a dataset or host the `@emoji-components/data` folder:

```tsx
<EmojiProvider data={async () => (await import("@emoji-components/data/en/iamcal.json")).default}>
<EmojiProvider data={localeData(locale, { baseUrl: "/emoji-data" })}>
```

More examples, such as semantic search, custom emoji, and other virtualizers, are in [Examples](/examples/).

## API reference

Every part forwards its ref, spreads other props onto its element, and takes these props.

<PropsTable rows={api.part} />

A handler you pass to a part runs before the part's own. Call `event.preventEmojiComponentsHandler()` to skip the part's handler.

Each controllable state has three props, such as `query`, `defaultQuery`, and `onQueryChange(value, details)`. `details.cancel()` keeps the current state.

Server Components can render the parts. Parts that take a function child, such as `List`, need a Client Component.

Shared types: `EmojiSelection`, `EmojiItem`, `EmojiRecord`, `CustomEmoji`, `CategoryOption`, `Dataset`, `EmojiDataInput`, `EmojiSearch`, `EmojiLabels`, `Frequents`, `SkinToneValue`, `EmojiImageUrl`, `EmojiStore`.

`onSelect` receives an `EmojiSelection`. Insert `emoji` as text, or, for a custom emoji, draw `imageUrl` or keep `shortcode`.
